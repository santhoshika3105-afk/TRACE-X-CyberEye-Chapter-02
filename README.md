# \# TRACE//X — CyberEye Chapter 02

# 

# \*\*A cinematic cybersecurity investigation visualisation built with Python.\*\*

# 

# TRACE//X Chapter 02 presents a simulated security investigation through animated visual storytelling, showing how signals, network events, anomalies, and forensic timelines can be visualised.

# 

# \## Features

# 

# \- CyberEye signal handoff animation

# \- Animated signal-tracing tunnel

# \- Simulated network event graph

# \- Rule-based anomaly flag visualisation

# \- Forensic event timeline

# \- Cinematic closing sequence

# 

# \## Technology Stack

# 

# \- Python 3.13

# \- Pillow

# \- NumPy

# \- ImageIO

# \- ImageIO-FFmpeg

# \- Pytest

#
